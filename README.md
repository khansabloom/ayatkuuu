# 🌸 Lanjut Ayat — Juz 30

Versi playable untuk GitHub Pages.

## Fitur
- 🎮 Quiz lanjut ayat
- 📖 Mode pilih surah / campur soal
- ❤️ 3 nyawa
- ⏱️ Timer 15 detik
- 🔥 Combo
- 🏆 High score tersimpan di browser
- ✨ Feedback benar/salah
- 🌙 Dark mode
- 🔊 Efek suara tanpa file audio eksternal
- 📱 Responsive HP, tablet, dan laptop
- 🗂️ Soal terpisah di `questions.json`

## Upload ke GitHub Pages
1. Buat repository baru.
2. Upload **semua file** dari ZIP ini ke root repository.
3. Pastikan `index.html`, `style.css`, `script.js`, dan `questions.json` berada satu folder.
4. GitHub → **Settings → Pages**.
5. Pada Source pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu Save.
7. Buka URL Pages yang diberikan GitHub.

> Catatan: versi ini berisi kumpulan soal Juz 30 yang sudah dibuat sebagai starter playable. Dataset dapat diperluas di `questions.json` tanpa mengubah tampilan game.
