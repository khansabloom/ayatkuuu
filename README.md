# Lanjut Ayat — Juz 30

Opening page game bertema pink, ungu, putih.

## Cara menjalankan
Buka `index.html` di browser.

## GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file di folder ini ke repository.
3. Pastikan `index.html` berada di bagian paling luar repository.
4. Buka Settings → Pages.
5. Pilih Deploy from a branch → branch `main` → folder `/root`.
6. Save. Tunggu beberapa saat sampai link GitHub Pages aktif.

File:
- index.html — halaman utama
- style.css — desain dan animasi
- script.js — interaksi tombol
- questions.json — database awal soal Juz 30
